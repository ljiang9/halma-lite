# halma-lite

极简跳棋（Halma）：8×8 棋盘，每方 6 枚棋子，从一角出发，全部送进对角营地者胜。
纯 Python 标准库，无第三方依赖。

## 玩法

- 你执黑方（●），左上开局；目标：把 6 枚棋子**全部**送进右下营地。AI 执白方（○）。
- 走法：
  - **单步**：八方向走到相邻空位，一回合只能走一格；
  - **跳跃**：跳过相邻任意一枚棋子（己方/对方均可）落到空位，**可以连跳**；
  - 单步和跳跃不能混在同一手里；
  - 已经进入目标营地的棋子**不许再出来**（可在营内调整位置）。
- 输入走法如 `a8-b7`、`c6-e4-g2`（连跳），`q` 退出。

## 用法

```bash
python3 -m halma_lite              # 人机对战（需要终端）
python3 -m halma_lite --auto      # AI 对 AI 自动演示（默认 10 局）
python3 -m halma_lite --auto --games 50 --seed 42
python3 -m halma_lite --auto --verbose   # 打印每局结果
```

## 设计取舍

- 棋盘 8×8、每方 6 子（经典 Halma 是 16×16/19 子，这里是轻量版）。
- AI 是贪心算法：每手选择让"棋子到目标营总距离"最小的走法（贪心分配目标格），
  进营走法优先，平局随机打破。没有深度搜索。

## 真实验证记录

- `py_compile halma_lite.py __main__.py`：通过
- 单元测试 11 项全过：连跳路径合法、三种非法走法被拒绝、
  六子全进营判胜/一子在外不判胜、营内棋子走法不出营、自动对局正常结束、AI 走法不增加总距离
- `--auto --games 10 --seed 42`：10 局全部正常结束，黑方胜 5、白方胜 5、和棋 0，平均 38.7 手/局
- 非终端运行交互模式：中文提示并 exit 2
- 无 TODO/FIXME 占位；`__pycache__` 已清理

## 诚实局限

- AI 只是贪心启发式，不会长远规划（比如不会主动让路、不会算多手连跳配合）；
  人类玩家熟悉规则后通常能赢它。
- 8×8 轻量规则与经典 Halma（16×16、19 子）不同，策略深度有限。
- 交互是文本回合制，无图形界面、无悔棋、无存档。
- Python 3.10+。
